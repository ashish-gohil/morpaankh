# Hindi copy review

Every Hindi message this service can send, beside the English it is saying.
Rendered with sample values, so this is what a customer actually reads.

**What to do with this file.** Read the Hindi. Where it is wrong, stiff, or
says something the English does not, edit `messages/templates.hi.mjs` or
`messages/session.hi.mjs` and run `npm run dryrun:render -- --lang hi` again.
Nothing here has been submitted to Meta yet, so the copy is still free to
change. Once a template is approved, changing a word means a new version
name and another review.

**What must stay true.** Same facts as the English, nothing added and nothing
dropped. No emoji, no en or em dash. A body that names a button must use that
button's Hindi text exactly. A UTILITY template must carry no offer wording at
all, or Meta reclassifies it as marketing and puts a per-customer cap on the
order confirmation.

Generated by `scripts/dryrun-render.mjs --lang hi`. Do not edit this file by
hand: it is regenerated, and the registries are the source.
